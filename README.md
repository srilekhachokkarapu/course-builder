# course-builder
# 📚 Smart Course Builder Using GEN AI

An AI-powered course generation platform built using Python and Streamlit that helps users create detailed learning courses instantly with the help of Generative AI.

This project allows users to generate customized course content based on topic, difficulty level, duration, learning style, and target audience. The application also provides module-wise course structure, recommended YouTube learning resources, PDF export functionality, and user authentication.

---

# 🚀 Features

- 🔐 User Login & Signup System
- 🤖 AI-Powered Course Generation
- 📖 Detailed Module-Based Learning Content
- 🎯 Personalized Course Creation
- 📺 Recommended YouTube Learning Links
- 📥 Download Complete Course as PDF
- 💾 Persistent User Course Storage
- 🖥️ Interactive and Simple Streamlit UI

---

# 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- JSON
- FPDF

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/srilekhachokkarapu/smart-course-builder-genai.git

2️⃣ Open Project Folder

cd smart-course-builder-genai

3️⃣ Install Required Libraries

pip install -r requirements.txt

4️⃣ Run the Streamlit Application

streamlit run git.py


---

🔑 API Key Setup

Create a folder named:

.streamlit

Inside that folder, create a file named:

secrets.toml

Add your Gemini API key inside it:

GEMINI_API_KEY = "YOUR_API_KEY"
